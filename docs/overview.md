# 目的とスコープ

正面〜準正面の顔写真から顔ランドマークと寸法比を抽出し、日本人の参照統計と比較して、採用した顔形態が平均からどの程度離れているかを可視化する。
MVP v1の目的は、個票取得を待たず、画像入力からスコア表示までの仕組みを作り、実際の写真で妥当性を検証することである。

## 指標の思想

MVPでは「平均顔に近いほど美しい」という仮説を明示的に置く。
実際に計測する対象は、3つの寸法比による形態統計上の平均への近さである。
顔全体の美しさや普遍的で客観的な美醜を測定するとは主張しない。

正式な指標名は**平均顔近似スコア**とする。
美形度との関係を説明するときは「平均顔に近いほど美しいという本アプリの仮説に基づく指標」と併記する。
近似の前提と理論上の位置の意味は[統計モデル](statistics.md)に定義する。

**典型度／珍しさ**は、局所密度などから評価する別概念として扱う。
平均ベクトルからの距離と同一視せず、MVPスコアへ混ぜない。
将来導入する場合も、平均顔近似スコアとは別の指標として定義する。

## MVPの対象

- 正面〜準正面の顔1名の静止画像アップロード。
- ユーザーによる参照集団の選択。
- 画像品質の検査と、解析不可理由の表示。
- 公開平均値と標準偏差に基づく3比率の近似モデル。
- 近似zスコア、近似マハラノビス距離、平均顔近似スコアの表示。
- 計測点と計測線の可視化。
- レスポンシブWeb画面とサーバー内で完結する解析。

参照群の年齢範囲、性別、地域的な制約は[dataset.md](dataset.md)を参照する。
対象外年齢を既存群へ強制割当てしない。

## MVPで扱わないもの

- 画像からの人種、民族、性別、年齢の推定。
- 本人確認、顔認証、医学的診断。
- 顔写真からの実寸mm推定。
- 「美人／不美人」の二値判定やカテゴリ判定。
- 実測人口順位の表示、局所密度に基づく典型度／珍しさの算出。
- カメラ直接撮影、顔画像の永続保存。
- 個票取得、個票由来の分布、Ledoit-Wolf共分散を必須とする統計処理。

## 将来機能

個票取得後は同じ特徴量、UI、APIを維持して `empirical` モデルへ交換する。
導入時期はTODOとし、公開統計量モデルとの比較を行う。
カメラ撮影、妥当性確認後の特徴量追加、典型度、魅力度研究の別レイヤーでの説明は将来候補とする。
画像保存は明示的同意と別途の保存設計が必要であり、導入自体も未決定である。
