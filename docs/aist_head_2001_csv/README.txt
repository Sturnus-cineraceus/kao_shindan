AIST 日本人頭部寸法データベース2001 CSV転記

出典（正本）:
https://www.airc.aist.go.jp/dhrt/head/

収録ファイル:
- measurement_items.csv: HTML表「頭部寸法項目一覧」18項目
- subject_summary.csv: HTML表「1.3 被験者」の4群×4項目
- statistics_image_sources.csv: 「3. 統計量」の4枚のAIST GIFへの直接URL
- item17_nose_height.csv: 会話で提示されたAISTの項目17画像を転記

方針:
- AISTの当該データベース以外の値は使用していない。
- 他資料による補正・置換はしていない。
- GIF画像の未確認セルを推測で埋めていない。
- subject_summary.csv の青年女性身長S.D.「51.1」はWebページのHTML抽出結果をそのまま記録しており、外部情報による訂正はしていない。
