# テスト戦略

本書は境界値、画像寿命、非機能要件を含む検証計画を定める。
数式と閾値の定義は各専門文書を参照し、期待値を実装の出力から逆算しない。

## 単体テスト

| 対象 | 確認する性質 |
| --- | --- |
| ランドマーク距離 | 既知座標で距離が一致し、点の交換で値が変わらない |
| normalized coordinate → pixel | 正方形と非正方形画像で幅と高さを正しく適用する |
| 比率 | 固定順の3比率になり、等倍率変換でほぼ不変となる |
| feature extraction | 4採用点ペア、欠損点、寸法不正、非有限座標、0分母を合成ランドマークで確認する |
| デルタ法 | 平均、分散、標準偏差が手計算の期待値と一致する |
| 共分散近似 | 共通分母由来の非対角成分を持ち、行列が対称となる |
| 正則化 | 設定した値を使い、不安定行列と回復不能行列を区別する |
| 近似zスコア | 比率の近似標準偏差を使い、平均で0、大小で符号が変わる |
| マハラノビス距離 | 既知の正定値行列で期待値と一致し、平均で0となる |
| chi-squareスコア | 自由度3、距離0で100、距離増加で単調減少、有限な0〜100となる |
| validation | 各閾値の直前、ちょうど、直後で仕様どおりに判定する |
| 参照データ | 出典と照合した転記値、単位、有効標本数を固定する |

例えば非正方形画像の距離は[image-analysis.md](image-analysis.md)の手計算例を使う。
統計値は単純な合成入力で独立に計算した期待値を使い、比率の標準偏差へ元寸法のSDを流用する誤りを検出する。
検証用の合成数値を実際の参照データとして扱わない。

## 境界値と異常系

- 写真側と参照側の分母0、負値、極小値を検出する。
- 元SDが0、比率の近似分散が0、SDが負または非有限の場合を区別する。
- 共分散行列の特異、非正定値、極端な条件数と正則化後の挙動を確認する。
- 座標、特徴、参照値のNaNと無限大を検出し、スコアを返さない。
- 必須点と行列の欠損、未知の参照群、特徴の順序不一致を拒否する。
- 極端な画像サイズ、縦長／横長、上限直前／ちょうど／超過を検証する。
- 空ファイル、破損画像、拡張子とMIMEの偽装、未対応形式、展開時に巨大化する入力を拒否する。
- 途中失敗でも元画像、中間画像、一時ファイルが残らないことを確認する。

数値異常や品質不合格を0点の成功結果へ変換しない。
原SDが0でも分母の分散で比率分散が正になるケースを含め、無条件な除算失敗と混同しない。

## 画像による妥当性検証

20〜30枚以上の条件を変えた写真を用意し、最低限次を含める。

| 条件 | 主な確認対象 |
| --- | --- |
| 正面、適正露出 | 基本成功、採用点と計測線、3比率 |
| yawの変化 | 横向き判定と測定誤差 |
| pitchの変化 | 上下向き判定と測定誤差 |
| rollの変化 | 傾き判定と符号規約 |
| 口開き | 閉口条件 |
| 片目と両目の閉眼 | 左右どちらでも拒否するか |
| 低照度、黒つぶれ | 平均輝度と暗部の割合 |
| 白飛び、過露出 | 平均輝度と明部の割合 |
| ぼけ | Laplacian variance |
| 顔欠け、画像端、遮蔽 | 必須点と境界条件、検出限界 |
| 複数人、顔なし | 成功扱いしないこと |
| 小さい顔 | Face Oval bbox比率 |
| 撮影距離、広角、視線の変化 | 比率化で除けない誤差 |
| 正方形、非正方形、等倍率リサイズ | 座標変換と比率の再現性 |

人手で確認した正解ラベルと判定を比較し、誤拒否と誤受入を分けて記録する。
初期閾値の最終採用値、許容誤差、合格率の数値は要検証とする。
検証画像は同意と利用条件を確認して扱い、顔画像を通常ログや公開リポジトリへ不用意に追加しない。
検証用画像の保管方法は、MVPのアップロード保存とは分離して決める。

## 回帰テスト

同じテスト画像に対して、採用点の計測値、3比率、品質コード、zスコア、距離、スコアを比較できるようにする。
画像の識別子と、MediaPipeモデル、参照データ、algorithm version、configurationを固定する。
画像内容をログへ出力せず、版と期待結果を対応づける。

モデル、閾値、画像前処理、依存ライブラリの変更時に、意図しない大きな変化がないか確認する。
差の許容幅は実測後に設定し、理由なしに期待値を更新しない。
承認した仕様変更による差は変更理由とともに記録する。
個票取得後は同一写真の `summary_delta` と `empirical` を並べ、近似誤差と計測誤差を分けて評価する。

## 結合と非機能の検証

Docker Compose起動、入力画面、参照群選択、解析、結果表示、画像破棄までを通して確認する。
不合格時にはスコアではなく撮り直し理由が表示されることを確認する。
初回とウォーム状態の時間、並列時のCPUとメモリ、繰り返し後のメモリとディスクを計測する。
異常画像、プロセス異常、コンテナ再起動、タイムアウトで他の要求と復旧に与える影響を確認する。
CSRF、エスケープ、キャッシュ制御、ログ禁止情報、health／readinessも検証する。
現行主要ブラウザ、狭い画面、キーボード操作、色に依存しない説明を確認する。

## MVP完了条件

MVPは次を満たす。

- Docker Composeで起動でき、画像1枚をアップロードできる。
- 参照集団を選択でき、MediaPipeで1顔を解析できる。
- 採用3特徴を取得し、公開統計量からデルタ法近似モデルを生成できる。
- 近似zスコア、近似マハラノビス距離、0〜100の平均顔近似スコアを表示できる。
- 不適切な画像を理由付きで拒否できる。
- 元画像を永続保存せず、結果に「公開統計量から推定した近似値」と明示する。

本書のテスト項目は実装後に実行する検証計画であり、現在すでに合格したことを意味しない。
